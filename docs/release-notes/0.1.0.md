# GroupKeep 0.1.0

GroupKeep divides a group's expenses fairly: a meal out, a day trip, a vacation, a
community event or anything else. Add the people and what each one paid, choose how
to split it, and GroupKeep shows who owes whom, with a PDF report to share.

This is the first public release. Please read [Known limits](../known-limits.md).

## What's in 0.1.0

- **Group types,** each with a sensible way to split:

  | Type | Split by default | Extras |
  |---|---|---|
  | Simple | Equally | |
  | Meal | By item | Items, tax and tip |
  | Day Trip | Equally | Several dated expenses |
  | Vacation | By the days each person was there | Trip dates |
  | Community Event | By household size | Households, donations and sponsors |
  | All Others | Equally | Every way of splitting, donations |

- **Ways to split:** equally, by shares (for example a child counts as half), by
  percent, by exact amounts, by item (tax and tip follow each person's items) and by
  the days each person was there.
- **Adjustments for one person,** each with a reason: pays an exact amount, pays more
  or less, pays a percentage more or less, or pays nothing. The difference is shared
  among the others. Adjustments are listed on their own tab and in the PDF.
- **Settle up:** who pays whom, and how much.
- **Exact pennies:** leftover cents are given to a named person and every rounding is
  listed, so the totals always add up.
- **Currencies:** US dollar, euro, Japanese yen, British pound, Chinese yuan,
  Australian dollar and Canadian dollar, chosen per group.
- **A PDF report** of the group, its expenses, adjustments and roundings.
- **Groups are files** (`.groupkeep`) you save wherever you like.

## Install

### Windows (64-bit)

- **With MoneyKeep Launcher:** install the launcher, then choose **Install** on
  GroupKeep. It downloads the setup, checks it and runs it. Windows asks for
  administrator permission.
- **From the release:** download `groupkeep-0.1.0-windows-x64-setup.exe` and run it.
  It installs GroupKeep for all users in `C:\Program Files\GroupKeep` (Windows asks
  for administrator permission), with a Start menu shortcut and, if you choose, a
  desktop shortcut.

The setup is not signed yet, so Windows SmartScreen may warn: choose **More info**,
then **Run anyway**.

A newer setup updates GroupKeep in place. Uninstalling it (Settings > Apps > Installed
apps) never touches your `.groupkeep` files.

### Mac (macOS 11 or later, Apple silicon and Intel)

- **From the release:** download `groupkeep-0.1.0-macos-universal.dmg`, open it and
  drag GroupKeep to Applications.
- **With MoneyKeep Launcher:** on a Mac the launcher can't install GroupKeep yet (see
  [Known limits](../known-limits.md)). Install it from the release as above; the
  launcher then finds it, opens it and tells you when a new version is out.

This Mac build is not yet signed with an Apple Developer ID, so macOS warns the first
time you open it. Right-click (or Control-click) GroupKeep in Applications, then choose
**Open**, and confirm. If macOS doesn't offer **Open**, go to System Settings > Privacy
& Security, scroll down and choose **Open Anyway** next to GroupKeep. You only need to
do this once.

## Checking your download

Each release has a file called `SHA256SUMS.txt`. It lists a fingerprint (a SHA-256
checksum) for every file in the release. MoneyKeep Launcher checks it for you. To check
a file yourself:

- **Windows:** open PowerShell in the folder with the file and run
  `Get-FileHash .\groupkeep-0.1.0-windows-x64-setup.exe -Algorithm SHA256`
- **Mac:** open Terminal in the folder with the file and run
  `shasum -a 256 groupkeep-0.1.0-macos-universal.dmg`

Compare the long string it prints with the one next to the file's name in
`SHA256SUMS.txt` (capital and small letters count as the same). If they differ, don't
open the file: download it again.
